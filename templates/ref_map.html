Сопоставьте колонки вашего CSV. Обязательна колонка с названием товара (title).

Что означает колонка «Тип изображения» (type)
ЗначениеЧто получится
standartТовар на чистом белом фоне, студийное фото. Название сайта — на самом товаре (или в углу этикетки).
storageТовар на металлическом стеллаже склада. Название сайта — гравировкой на стеллаже.
post_imageИзображение для записи (не товар). Широкий кадр 21:9, название сайта на одном из объектов.
applicationПрименение товара строителями. Этикетка сохраняется, название сайта — на каске/спецодежде.
all_productСразу два изображения: storage + standart.
пустоПо умолчанию — standart.

Если колонки type в CSV нет — будет использован тип standart.
