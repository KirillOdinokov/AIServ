Инструкция: как работает генерация по референсам

1. Что делает режим

По каждому товару берётся картинка-референс и на её основе генерируется новое изображение с вашим брендом. Готовые картинки сохраняются на диск — на сайт автоматически не загружаются.

2. CSV

КолонкаОбязательноЧто указывать
post_titleДаНазвание товара (или записи при type=post_image)
IDЖелательноID товара — в имени выходного файла
imageНетПрямая ссылка на референс; если пусто — найдётся автоматически
typeНетТип изображения (по умолчанию standart)

3. Типы изображений

standart — товар на белом фоне; storage — на стеллаже склада; post_image — широкий кадр для записи; application — применение строителями; all_product — storage + standart.

4. Откуда берётся референс

Если в image указана ссылка — используется она; иначе картинка ищется автоматически по названию (DuckDuckGo, самое крупное изображение).

5. Результат

После генерации выберите картинки и нажмите «Сохранить выбранные». Файлы появятся в images/png/ (исходники) и images/webp/ (готовые).
