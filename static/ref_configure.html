🖼️ Генерация по референсам

Задача

Будет наноситься на товар/этикетку/спецодежду в зависимости от типа изображения.

Не добавляет наклейки/этикетки/бренд. Изображение повторяет исходное, но без водяных знаков и посторонних надписей.

Опционально. Полупрозрачный PNG со шрифтом/логотипом, который будет нанесён поверх каждого сгенерированного изображения.

Генерация по референсу выполняется моделью FLUX.2 Klein.

Отмена
📖 Инструкция: как работает генерация по референсам

1. Что делает этот режим

По каждому товару берётся картинка-референс и на её основе генерируется новое изображение с вашим брендом (названием сайта). Готовые картинки сохраняются на диск — на сайт они не загружаются автоматически.

2. Как подготовить CSV-файл

Файл в формате CSV (разделитель — запятая или точка с запятой). Заголовки первой строки:

КолонкаОбязательноЧто указывать
post_titleДаНазвание товара (или записи, если type = post_image)
IDЖелательноID товара — используется в имени выходного файла
imageНетПрямая ссылка на картинку-референс. Если пусто — картинка будет найдена автоматически в интернете
typeНетТип изображения (см. ниже). По умолчанию standart

3. Типы изображений (колонка type)

ЗначениеЧто получитсяРазмер
standartТовар на белом фоне, студийное фото, бренд на товаре1:1
storageТовар на металлическом стеллаже склада, этикетка с названием и сайтом1:1
post_imageИзображение для записи (не товар). Широкая картинка, бренд на одном из объектов. Референс ищется в высоком разрешении (Full HD+)21:9
applicationПрименение товара строителями, бренд на спецодежде или каске1:1
all_productСразу 2 изображения: storage + standart1:1 ×2

4. Режим генерации

  • multimodal — генерация «по мотивам» референса (модель klein).

5. Откуда берётся референс

Если в колонке image указана ссылка — используется она. Если ссылки нет — картинка ищется автоматически по названию товара (через поисковик DuckDuckGo). Система выбирает самое крупное изображение из выдачи, чтобы не взять маленькое превью.

6. Где искать результат

После генерации выберите понравившиеся картинки и нажмите «Сохранить выбранные». Файлы появятся в папке задачи:

  • images/png/ — исходники в формате PNG (без потерь)
  • images/webp/ — готовые к загрузке сжатые WebP

Найти файлы можно через раздел «📁 Файлы» в шапке главной страницы (папка с номером задачи и суффиксом _ref_).
