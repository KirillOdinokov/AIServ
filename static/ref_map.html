🖼️ Сопоставление колонок (референсы)

Файл

Сопоставьте колонки вашего CSV. Обязательна колонка с названием товара (title).

📖 Что означает колонка «Тип изображения» (type)
ЗначениеЧто получится
standartТовар на чистом белом фоне, студийное фото. Название сайта — на самом товаре (или в углу этикетки, если она есть)
storageТовар на металлическом стеллаже склада. Название сайта — гравировкой на стеллаже, а не на товаре
post_imageИзображение для записи (не товар). Широкий кадр 21:9, название сайта на одном из объектов. Референс ищется в высоком разрешении
applicationПрименение товара строителями. Этикетка товара сохраняется, название сайта — только на каске или спецодежде рабочего
all_productСразу два изображения: storage + standart
пустоПо умолчанию — standart

Если колонки type в CSV нет — оставьте поле несопоставленным, будет использован тип standart.
